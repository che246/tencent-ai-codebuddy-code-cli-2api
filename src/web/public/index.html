                📝 系统提示词策略
                passthrough
              

              
            

            

              

                
                
                

                  custom: 替换客户端 system/developer 提示词为网关自有提示词；append: 在客户端原有 system 之后追加；passthrough: 完全透传客户端原始 system。
                

              

              

                
                
                

                  指定提示词文件绝对路径或相对路径（Windows 如 D:\AI\dsh-purge\v1.1.40_prompt.txt；Linux 部署路径如 /home/node_code/codebuddy-code/v1.1.40_prompt.txt，或直接填写相对路径 v1.1.40_prompt.txt）。跨系统部署时，输入 Windows 路径亦会自动按文件名同名兼容项目根目录。
                

              

            

          


          
          

            

              思考档位
            

            

              
              

                
              


              
              

                
                
                

                  模型没配单独档位时用这一档（客户端没传档位时网关补充；网关优先模式下也是改写目标）；模型不支持时落到不高于它的最高支持档。单个模型可在「模型与档位」页的「网关档位」列覆盖
                

              


              
              

                
网关优先 / 客户端优先

                

                  
                  
                  
                

                

                  逐模型的目标档在「模型与档位」页每行的「网关档位」列（选项即该模型「支持的思考档位」原样，可关思考的模型另有 off）；未单独配置时用上面的「默认网关档位」；模型不支持所选档时落到不高于它的最高支持档
                

              

            

          


          
          

            

              日志
            

            

              
              

                

                  记录调用来源 (客户端 IP / User-Agent)
                  
                

                

                  开启后，「运行日志」页的请求记录会显示每次调用来自哪个 IP、用什么客户端；关闭则归档与面板都不再出现来源信息。改动即时生效，无需重启。
                

              


              
              

                

                  记录请求上下文 (system / messages 原文)
                  
                

                

                  开启后，「请求事件日志」点任意一行可展开当轮发出去的提示词与消息。这是用户数据：会以明文写进归档文件（保留 7 天），仅在排查「上游为什么拒这条请求」时临时打开。
                

              

            

          


          
          

            

              

                

                  数据用途声明

                  这是对上游的数据用途声明，只影响 X-Private-Data 头，不改变请求内容。
